## 💻 Running the Programs

### 1. Clone the Repository

    git clone <your-repository-url>

### 2. Navigate into the Repository

    cd OOP-Lab

### 3. Compile a Program

    g++ program.cpp -o program

### 4. Run the Program

**Windows:**

    program.exe

**Linux / macOS:**

    ./program
